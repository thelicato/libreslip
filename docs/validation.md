Task 13 refines the existing optional Client delivery and foreground Server receiver. Physical communication between two separate Android devices on the same Wi-Fi network remains unverified. Router client isolation, network changes, multiple physical clients, mDNS evaluation, networking-data backup policy, larger-queue hardening and any decision about foreground-service hosting remain Task 14.

The Android document picker and share-sheet interaction were compiled into the release APK but were not manually repeated during Task 13. Export cancellation and destination behaviour remain platform-owned and unobserved here. The GitHub release workflow was not executed because no tag was pushed and no repository secrets were changed.

The physical printer result is user-reported evidence from Task 4. A transmitted printer state still means that the phone completed its socket write, not that LibreSlip can prove paper output. The app never automatically retries an uncertain print. USB printing remains outside the current implementation.

The preview APK uses a development validation certificate and is not a production upgrade baseline. The repository owner must keep the long-lived release keystore securely backed up, configure the documented GitHub secrets, and publish only from a matching `v0.13.0` tag.
