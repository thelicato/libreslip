Task 10 does not receive or deliver orders. Server mode stores only the selected mode and displays the foundation state. Task 11 must add authenticated foreground-only local HTTPS, explicit pairing, idempotent receipt storage and the received/completed board before any server operation can be claimed. The release manifest intentionally has no internet permission.

The Android document picker and share-sheet interaction were compiled into the release APK but were not manually exercised on a handset during task 10. Export cancellation and destination behaviour remain platform-owned and unobserved here. The GitHub workflow was linted locally during task 6 but was not executed on GitHub because no tag was pushed and no repository secrets were changed.

The physical printer result is user-reported evidence from task 4. A transmitted printer state still means that the phone completed its socket write, not that LibreSlip can prove paper output. The app never automatically retries an uncertain print. USB printing remains outside the current implementation.

The preview APK uses a disposable certificate created only for validation and is not a production upgrade baseline. The repository owner must generate and securely back up the long-lived release keystore, configure the documented GitHub secrets, and publish only from a matching `v0.10.0` tag.
